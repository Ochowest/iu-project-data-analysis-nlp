📌 Project: NLP Topic Extraction on Amazon Fine Food Reviews
Course

Project: Data Analysis (CSEBDSEDA02) – IU International University of Applied Sciences

Objective

This project applies Natural Language Processing (NLP) techniques to a large collection of unstructured customer review texts. The goal is to preprocess the text data, convert it into numerical representations, and extract prevalent topics using topic modeling methods.

Dataset

Amazon Fine Food Reviews Dataset (Kaggle)
The dataset contains over 500,000 customer reviews with plain text feedback and additional metadata such as ratings and timestamps.

Methods

Text preprocessing (cleaning, tokenization, stopword removal)

Vectorization using Bag-of-Words and TF-IDF

Topic modeling using LDA and NMF

Tools

Python

Google Colab

pandas, numpy

nltk / spaCy

scikit-learn
